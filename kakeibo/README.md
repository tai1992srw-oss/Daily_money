# 家計簿（Web アプリ）

口座のお金とデビットカードの利用を、ひとつの画面で管理する家計簿です。Google Apps Script の Web アプリとして動き、スマホのブラウザから開いて使います。データはあなたの Google アカウント内のスプレッドシート「家計簿データ」に保存されます。

## できること

- **デビット利用の自動記録**: ドコモSMTBネット銀行の通知メールを 15 分おきに読み、店名・金額・日時・カテゴリ付きで記録します。返金や確定金額の変更も反映します。
- **店ごとのカテゴリの学習**: 記録のカテゴリや店名を直すと、「この店は今後も同じ」にできます。同じ店の過去の記録もまとめて直ります。
- **デビット以外の口座の動き**: 振込入金・出金（PayPay など）・振込のメールが届くと、「金額の入力待ち」として画面の上に出ます。メールに金額が書かれていないので、金額だけ入れます。
- **手入力**: 右下の「+」から、支出・収入を自分で記録できます。現金払いは「現金・その他」を選ぶと口座残高に影響しません。
- **口座残高**: 記録から計算して表示します。メールが来ない引き落としなどでずれたら、「設定」で実際の残高を入れて合わせます。
- **集計**: 月ごとのカテゴリ別支出を見られます。「振替・チャージ」と「残高調整」は支出の集計に入りません。

## セットアップ

1. [script.google.com](https://script.google.com/) で新しいプロジェクトを作ります。
2. ファイルを 4 つ作り、このフォルダの同名ファイルの中身を貼り付けます。
   - スクリプト: `Parser`、`Logic`、`Code`（最初からある `コード.gs` は消すか、どれかに使います）
   - HTML: `index`（名前は必ず `index`）
3. 関数 `setup` を実行します。Google の権限確認のあと、保存用のスプレッドシートと 15 分おきのメール取り込みが作られます。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、実行ユーザーを「自分」、アクセスできるユーザーを「自分のみ」にしてデプロイします。
5. 表示された URL をスマホで開きます（同じ Google アカウントでログインしたブラウザで）。ホーム画面に追加すると、アプリのように開けます。
6. アプリの「設定」で「過去 90 日分を取り込む」を押し、そのあと「残高を合わせる」に今の口座残高を入れます。

コードを更新したときは、「デプロイを管理」から新しいバージョンにしてください。

## 構成

| ファイル | 役割 |
| --- | --- |
| `Parser.js` | 銀行メールの読み取りと、店名 → カテゴリのルール照合 |
| `Logic.js` | 記録の追加・編集、メール取り込み、残高計算 |
| `Code.js` | Apps Script とのつなぎ込み（画面の配信、スプレッドシート保存、Gmail 取得） |
| `index.html` | 画面 |
| `dev/` | 手元で画面を動かすための確認用サーバーと見本データ |

## 手元での確認

```
node --test test/parser.test.js test/logic.test.js
node dev/server.js   # http://localhost:8787 を開く（見本データで動く）
```

テストと確認用サーバーが動かすのは `Parser.js`・`Logic.js`・`index.html` です。`Code.js`（スプレッドシートと Gmail を触る部分）は Apps Script 上でしか動きません。

## 知っておくこと

- 口座振替や ATM など、銀行からメールが来ない動きは自動では入りません。手入力するか、残高合わせで調整します。
- 通知メールの店名はカード会社に届く加盟店名（英字やカナの略称）です。一度直せば次からはその名前で入ります。
- 外貨での確定通知で、利用時の通知が無かったものは「金額の入力待ち」になります。
