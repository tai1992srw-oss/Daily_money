# ダイエットレビュースキル

蓄積された食事・活動データを分析して講評し、その要約をシートに書き込む（アプリのカレンダー・詳細画面から後で見返せる）。

## 設定の読み込み

`.claude/diet-bot.local.json`（リポジトリルート直下、git管理外）から `api_url` と `token` を読む。
なければユーザーに尋ねて保存する（meal-log スキルと共通のファイル）。

## 手順

1. **期間の判断**: 「今日のまとめ」→日次、「今週/最近」→7日、指定があればその期間。
   日付境界は午前5時（API側で処理済み。「今日」はAPIの返す date に従う）。
2. **データ取得**:
   - 日次: `curl -sL '<api_url>?token=<token>&action=today'`
   - 週次など: `curl -sL '<api_url>?token=<token>&action=summary&days=7'`
   - 特定日の詳細が必要なら `?action=today&date=YYYY-MM-DD`
3. **分析**: 以下の観点で講評する。データにあるものだけ使い、無い項目は触れない。
   - カロリー収支（摂取 − 消費）の傾向。単日でなく数日の流れで見る
   - PFCバランス（特にタンパク質不足と脂質過多に注目）
   - 体重の推移（日々の上下でなく週単位のトレンドで評価する）
   - 歩数・睡眠と食事の関係（睡眠不足の日の過食傾向など、気づいたパターン）
   - 良かった点を必ず1つ以上挙げる。続けられることを最優先に、具体的な提案は1〜2個に絞る
4. **シートに記録**: 講評の**要約（200〜400字程度）**を addAdvice で書き込む。
   meal-log スキルと同じ注意（UTF-8ファイル経由・`-X POST` 禁止・エラー時は重複確認）に従うこと:

```bash
BODY=<scratchpad>/advice.json
cat > "$BODY" <<'EOF'
{"token":"<token>","action":"addAdvice","type":"週次レビュー","content":"摂取は平均1750kcalで目標内。タンパク質が平均55gと不足気味なので朝に卵かヨーグルトを追加したい。歩数が多い日は収支が安定する傾向。体重は週で-0.3kgと順調。"}
EOF
curl -s -L --data-binary @"$BODY" -H 'Content-Type: application/json; charset=utf-8' '<api_url>'
```

   - `type` は「日次レビュー」「週次レビュー」「提案」のいずれか
   - 過去日に対するレビューは `"date":"YYYY-MM-DD"` を付ける（省略時は今日）
5. **報告**: ユーザーには要約より詳しい講評を伝える（シートには要約、チャットには全文）。

## 注意

- 医学的な診断はしない。極端な減量ペース（週1kg超）や過度な絶食傾向が見えたら、優しく注意を促す
- データが少ない（記録3日未満など）ときは無理に傾向を語らず、記録の継続を褒めて具体的な分析は次回に回す
- 同じ日に既にレビューがある場合（today の advice に同 type がある）は、上書きではなく差分・続報として書く
