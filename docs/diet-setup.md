# ダイエットログ セットアップ手順

このアプリは、Google スプレッドシート「ダイエットログ」をデータのハブとして使います。

> **重要な仕様**: 日付は**午前5時**に切り替わります（深夜0〜5時の食事は前日扱い）。
> シートのタブは「食事ログ」「活動ログ」「アドバイス」の3つで、後の2つはGASが自動作成します。

> **GAS を更新するとき**: Apps Script エディタで `gas/Code.gs` を丸ごと貼り替え、
> `TOKEN` だけ自分の値に戻す → 「デプロイ → デプロイを管理 → 編集(鉛筆) → 新バージョン」で反映。
> URL は変わりません。ヘッダー（活動ログの距離・睡眠・体重、食事ログの写真URL・店名・店URL）は
> 初回アクセス時に自動で追加されます。
>
> **写真対応（v3）に上げるときは Drive の権限を追加で承認する必要があります**。貼り替え後に
> エディタで関数 `photoFolder_` を一度「実行」し、Google ドライブへのアクセスを許可してください
> （許可しないと写真の保存が `unauthorized` ではなく Drive エラーで失敗します）。
>
> **お店タブ（v4）を使うにも貼り替えが必要です**（`action=places` と食事ログの「店エリア」列が
> 増えます）。権限の追加承認は不要で、貼り替えて新バージョンをデプロイするだけです。

```
Pixel Watch ─▶ Fitbit ─▶ Health Connect ─▶ アプリ ─┐（活動データを書き込み）
                                                    ▼
Claude チャット（食事を記録）──▶ GAS Web API ──▶ スプレッドシート「ダイエットログ」
                                                    │
アプリ ◀── 食事ログ・カロリー収支を取得 ◀──────────┘
```

セットアップは3ステップです。

## 1. GAS（Google Apps Script）Web API のデプロイ — 約10分

1. スプレッドシート「ダイエットログ」を開く
   https://docs.google.com/spreadsheets/d/1i3VtQO3js19V1iKXbzcshNzQifBcrvDW9GztvV4c12A/edit
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタの `コード.gs` の中身を全部消し、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) を貼り付ける
4. 先頭付近の `const TOKEN = 'CHANGE_ME_TO_RANDOM_STRING';` を**ランダムな長い文字列**に変更する
   （例: パスワードマネージャで32文字生成。これが実質のAPIキーになります）
5. 右上 **デプロイ → 新しいデプロイ** → 種類「**ウェブアプリ**」を選択
   - 説明: 任意（例: diet-log-api）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（URLとトークンを知らない限りアクセスできません）
6. **デプロイ** を押し、承認を求められたらGoogleアカウントで許可する
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxx/exec`）を控える

> コードを更新したときは「デプロイ → デプロイを管理 → 編集(鉛筆) → 新バージョン」で反映されます（URLは変わりません）。

動作確認（ブラウザで開く）:

```
https://script.google.com/macros/s/xxxx/exec?token=あなたのトークン&action=today
```

`{"ok":true,"date":"...","meals":[...]}` のようなJSONが返ればOKです。

## 2. Pixel Watch → Health Connect の同期を有効にする — 約2分

1. スマホの **Fitbit アプリ**を開く
2. アイコン → **Fitbitの設定 → Health Connect** → 同期を**オン**にする
3. スマホの **Health Connect**（設定 → セキュリティとプライバシー → Health Connect など）で
   Fitbit からの「歩数」「消費カロリー」の書き込みが許可されていることを確認する

## 3. アプリ側の設定

1. アプリをビルド・インストールし、**今日** タブを開く
2. 初回に表示される設定画面（⚙アイコンからも開けます）で以下を入力:
   - **API URL**: 手順1で控えたウェブアプリのURL
   - **トークン**: 手順1で決めたランダム文字列
   - **目標摂取カロリー**: 例 1750
   - **目標タンパク質**: 例 125（g/日）
3. **Health Connect と連携** ボタンを押し、歩数・消費カロリー・距離・睡眠・体重の読み取りを許可する

以上で、今日タブに「摂取・消費・収支」が表示され、同期のたびに活動データがスプレッドシートにも書き込まれます。

## 日々の使い方

- **食事の記録**: Claude のチャット/Cowork にいつも通り食べたものを送る。
  このリポジトリのセッションなら `/meal-log 唐揚げ定食とビール1杯` でカロリー推定〜シート追記まで自動で行われます
  （初回はAPI URLとトークンを聞かれます。`.claude/diet-bot.local.json` に保存され、gitには含まれません）
- **写真の記録**: 食事の写真をそのままチャットに貼れば、Drive の「ダイエットログ写真」フォルダに
  保存され、アプリの食事カードにサムネイルが出ます（タップで拡大）。写真は量の推定にも使われます。
  記録した後で写真だけ送っても、その日の最後の食事に後付けされます
- **店の記録**: Google マップ（`maps.app.goo.gl` など）や食べログの URL を送ると、店名を取り出して
  食事と一緒に記録します。アプリでは店名チップをタップするとその URL が開きます。
  店名が自動で取れないときは聞かれるので答えてください
- **店名だけでもOK**: URL が面倒なら「北戸田の琥羽」のように名前だけでも構いません。
  Web 検索で店のページを探して記録します（同名の店があるときは確認されます）。
  見つからなければ、その名前で開くマップの検索リンクを代わりに残します
- **収支の確認**: アプリの今日タブ（開くたびに同期。手動同期ボタンもあり）
- **過去の見返し**: カレンダータブ。日をタップすると食事・活動・アドバイスの詳細が見られます
- **行った店の見返し**: お店タブ。都道府県ごとにまとまって並び、「エリア順 / よく行く順 /
  最近行った順」で並べ替え、都道府県チップで絞り込みができます。店をタップすると地図が開きます
- **振り返り**: チャットで「今週のまとめして」→ `/diet-review` スキルが講評を生成し、
  要約をアドバイスシートに記録します（アプリの今日タブ・カレンダーに表示されます）

## 行った店を Google マップで見たい場合

Google マップの「保存済みリスト」に**自動で追加する方法はありません**（保存リストに書き込む
公開 API が存在しないため）。手でリストに入れたいときは、お店タブや食事カードから地図を開いて
「保存」を押してください。地図上でまとめて見たいだけなら、無料の**マイマップ**が使えます:

1. `python .claude/skills/meal-log/places_csv.py` を実行して `places.csv` を作る
2. [マイマップ](https://mymaps.google.com) で「新しい地図を作成 → インポート」から CSV を選ぶ
3. 目印の場所にする列 → **場所**、目印のタイトルにする列 → **店名** を指定する

1レイヤ2000行・10レイヤまで、いずれも無料です。位置がズレた店は地図上でピンを動かせます。

## トラブルシューティング

- **アプリに「unauthorized」と出る**: トークンの不一致。GAS側の `TOKEN` とアプリ設定を確認
- **消費カロリーが0のまま**: Health Connect の権限を確認。Fitbit の同期は数時間おきのため、
  Fitbit アプリを開いて手動同期すると反映が早まります
- **写真が保存できない / アプリでサムネイルが出ない**: GAS を貼り替えた後に Drive の承認をしたか確認
  （上記「写真対応（v3）」の注記）。写真は「リンクを知っている全員が閲覧可」で共有されるため、
  Drive 側で共有設定を戻すとアプリから見えなくなります
- **写真を消したい**: Drive の「ダイエットログ写真」フォルダから削除し、食事ログの写真URLセルも空にします
- **シートの日付がズレる**: GAS の `TZ`（Asia/Tokyo）と、スプレッドシートの
  設定 → タイムゾーンが東京になっているか確認
