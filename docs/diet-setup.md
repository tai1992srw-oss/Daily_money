# ダイエット機能 セットアップ手順

このアプリのカロリータブは、Google スプレッドシート「ダイエットログ」をデータのハブとして使います。

```
Pixel Watch ─▶ Fitbit ─▶ Health Connect ─▶ アプリ ─┐（活動データを書き込み）
                                                    ▼
Claude チャット（食事を記録）──▶ GAS Web API ──▶ スプレッドシート「ダイエットログ」
                                                    │
アプリ ◀── 食事ログ・カロリー収支を取得 ◀──────────┘
```

セットアップは3ステップです。

## 1. GAS（Google Apps Script）Web API のデプロイ — 約10分

1. スプレッドシート「ダイエットログ」を開く
   https://docs.google.com/spreadsheets/d/1i3VtQO3js19V1iKXbzcshNzQifBcrvDW9GztvV4c12A/edit
2. メニュー **拡張機能 → Apps Script** を開く
3. エディタの `コード.gs` の中身を全部消し、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) を貼り付ける
4. 先頭付近の `const TOKEN = 'CHANGE_ME_TO_RANDOM_STRING';` を**ランダムな長い文字列**に変更する
   （例: パスワードマネージャで32文字生成。これが実質のAPIキーになります）
5. 右上 **デプロイ → 新しいデプロイ** → 種類「**ウェブアプリ**」を選択
   - 説明: 任意（例: diet-log-api）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（URLとトークンを知らない限りアクセスできません）
6. **デプロイ** を押し、承認を求められたらGoogleアカウントで許可する
7. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxx/exec`）を控える

> コードを更新したときは「デプロイ → デプロイを管理 → 編集(鉛筆) → 新バージョン」で反映されます（URLは変わりません）。

動作確認（ブラウザで開く）:

```
https://script.google.com/macros/s/xxxx/exec?token=あなたのトークン&action=today
```

`{"ok":true,"date":"...","meals":[...]}` のようなJSONが返ればOKです。

## 2. Pixel Watch → Health Connect の同期を有効にする — 約2分

1. スマホの **Fitbit アプリ**を開く
2. アイコン → **Fitbitの設定 → Health Connect** → 同期を**オン**にする
3. スマホの **Health Connect**（設定 → セキュリティとプライバシー → Health Connect など）で
   Fitbit からの「歩数」「消費カロリー」の書き込みが許可されていることを確認する

## 3. アプリ側の設定

1. アプリをビルド・インストールし、下部タブの **カロリー** を開く
2. 初回に表示される設定画面（⚙アイコンからも開けます）で以下を入力:
   - **API URL**: 手順1で控えたウェブアプリのURL
   - **トークン**: 手順1で決めたランダム文字列
   - **目標摂取カロリー**: 例 1800
3. **Health Connect と連携** ボタンを押し、歩数・消費カロリーの読み取りを許可する

以上で、カロリータブに「摂取・消費・収支」が表示され、同期のたびに活動データがスプレッドシートにも書き込まれます。

## 日々の使い方

- **食事の記録**: Claude のチャット/Cowork にいつも通り食べたものを送る。
  このリポジトリのセッションなら `/meal-log 唐揚げ定食とビール1杯` でカロリー推定〜シート追記まで自動で行われます
  （初回はAPI URLとトークンを聞かれます。`.claude/diet-bot.local.json` に保存され、gitには含まれません）
- **収支の確認**: アプリのカロリータブを開く（開くたびに同期。手動同期ボタンもあり）
- **振り返り**: チャットで「今週のダイエットのまとめして」と言えば、Claude がシートの
  `?action=summary&days=7` を読んで摂取・消費の両面から講評できます

## トラブルシューティング

- **アプリに「unauthorized」と出る**: トークンの不一致。GAS側の `TOKEN` とアプリ設定を確認
- **消費カロリーが0のまま**: Health Connect の権限を確認。Fitbit の同期は数時間おきのため、
  Fitbit アプリを開いて手動同期すると反映が早まります
- **シートの日付がズレる**: GAS の `TZ`（Asia/Tokyo）と、スプレッドシートの
  設定 → タイムゾーンが東京になっているか確認
