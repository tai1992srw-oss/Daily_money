# デビット家計簿

ドコモSMTBネット銀行のデビット利用通知メール（Gmail）を読み取り、**店名とカテゴリ付き**で Google スプレッドシートに記録する Google Apps Script です。

もともとは Zaim に登録する想定でしたが、Zaim API が 2026 年 12 月 7 日で提供終了になるため、記録先をスプレッドシートにしています。外部サービスの登録やキーは要りません。

## できあがるシート

| シート | 中身 |
| --- | --- |
| 明細 | 1 利用 1 行。利用日・店名・金額・カテゴリ |
| 月別集計 | カテゴリ × 月の合計（自動計算） |
| ルール | 店名のキーワード → カテゴリ・表示名。ここを編集して振り分けを育てる |

メールの種類ごとの扱いは次のとおりです。

| メール | 処理 |
| --- | --- |
| ご利用のお知らせ | 明細に 1 行追加 |
| ご返金のお知らせ | マイナス金額の行を追加（合計から差し引かれる） |
| 引落しまたは入金処理のお知らせ | 利用時に記録済みなら何もしない。未記録なら追加（利用時に通知が来ない店の分）。金額が利用時と違えば「要確認」の行を追加 |
| ご利用不可・メンテナンス等 | 何もしない |

## セットアップ

1. [script.google.com](https://script.google.com/) で新しいプロジェクトを作り、`Parser.js` と `Main.js` の中身をそれぞれ貼り付けます。
2. `setup` を実行します。スプレッドシート「デビット家計簿」と 15 分おきのトリガーが作られ、実行ログにシートの URL が出ます。初回は Google の権限確認が出ます。
3. `backfill` を実行すると、過去 90 日分のメールがまとめて入ります。

## 振り分けの育て方

1. `明細` でカテゴリが「未分類」の行を見て、「メール上の店名」に出ている文字を `ルール` シートに足します。
2. `reclassify` を実行すると、「未分類」の行にだけルールが当て直されます。手で直したカテゴリは上書きされません。

ルールは上から順に見て最初に当たった行が使われます。大文字小文字と半角カナの違いは無視されます。

## 知っておくこと

- 通知メールの店名はカード会社に届く加盟店名（英字やカナの略称）です。`ルール` の「表示名」に書くと、その名前で記録されます。
- 通知メールは利用時点の金額です。確定時に金額が変わった場合や外貨の確定通知は、金額 0 の「要確認」行として残るので、手で直します。
- Zaim の口座連携はそのまま使えます。Zaim 側のデビットの記録（店名「デビット」）とは連動しないので、デビット分の内訳はこのシートで見ます。

## テスト

```
node --test test/parser.test.js test/main.test.js
```

メールの読み取りと、明細 1 行への変換までを対象にしています。Gmail の検索とシートへの書き込み部分は Apps Script 上での確認が必要です。
