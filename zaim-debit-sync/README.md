# Zaim デビット連携

ドコモSMTBネット銀行のデビット利用通知メール（Gmail）を読み取り、**店名とカテゴリ付き**で Zaim に自動登録する Google Apps Script です。

Zaim の口座連携ではデビットの店名が入らないため、店名が載っている通知メールのほうを情報源にします。

## 動き

15 分おきに Gmail を確認し、メールの種類ごとに次のように処理します。

| メール | 処理 |
| --- | --- |
| ご利用のお知らせ | 店名・金額・日付で Zaim に支出を登録 |
| ご返金のお知らせ | 同じ承認番号・同じ金額の登録を Zaim から削除 |
| 引落しまたは入金処理のお知らせ | 利用時に登録済みならスキップ。未登録なら支出として登録（利用時に通知が来ない店の分） |
| ご利用不可・メンテナンス等 | 何もしない |

カテゴリは、スプレッドシート「Zaimデビット連携」の `ルール` シートで決まります。店名にキーワードが含まれる最初の行が使われ、どれにも当たらなければ「その他／未分類」で登録されます。処理結果はすべて `ログ` シートに残り、手で確認が必要なものは結果欄が「要確認」で始まります。

## セットアップ

1. **Zaim にアプリを登録する**
   [Zaim Developers](https://dev.zaim.net/) で新しいアプリケーションを追加し、コンシューマ ID とコンシューマシークレットを控えます。サービスの URL は手順 2 のあとで設定します。
2. **Apps Script プロジェクトを作る**
   [script.google.com](https://script.google.com/) で新しいプロジェクトを作り、`Parser.js` と `Main.js` の中身をそれぞれ貼り付けます。
3. **ライブラリを追加する**
   エディタ左の「ライブラリ」に次の ID を入れ、名前を `OAuth1` のまま追加します。
   `1CXDCY5sqT9ph64fFwSzVtXnbjpSfWdRymafDrtIZ7Z_hwysTY7IIhi7s`
4. **キーを設定する**
   「プロジェクトの設定」→「スクリプト プロパティ」に `ZAIM_CONSUMER_KEY` と `ZAIM_CONSUMER_SECRET` を追加します。出金元の口座を付けたい場合は `ZAIM_ACCOUNT_NAME` に Zaim 上の口座名を入れます。
5. **コールバック URL を Zaim に登録する**
   Zaim Developers のアプリ設定で、サービスの URL を次の形にします（スクリプト ID は「プロジェクトの設定」にあります）。
   `https://script.google.com/macros/d/スクリプトID/usercallback`
6. **`setup` を実行する**
   スプレッドシートと 15 分おきのトリガーが作られます。初回は Google の権限確認が出ます。
7. **`authorize` を実行する**
   実行ログに出た URL を開き、Zaim で許可します。
8. **`dryRun` で確認する**
   Zaim には何も送らず、直近 3 日分のメールがどう振り分けられるかをログに出します。問題なければ、あとは放っておけば 15 分おきに登録されます。

## 二重計上を避ける

Zaim の口座連携を続けたままだと、同じ支払いが「連携で入った店名なしの記録」と「このスクリプトが入れた記録」の 2 件になります。Zaim 側で、連携で入ってくるデビットの記録を集計から外してください（該当の記録を「集計に含めない」にする、またはその口座の連携を止める）。

## 知っておくこと

- 通知メールの店名はカード会社に届く加盟店名（英字やカナの略称）です。`ルール` シートの「表示名」に書くと、Zaim にはその名前で登録されます。
- 通知メールは利用時点の金額です。確定時に金額が変わった場合は `ログ` に「要確認」と出るので、Zaim 側を手で直します。
- 外貨での確定通知は自動登録せず、「要確認」として残します。
- 見るのは直近 3 日分のメールです（`Main.js` の `LOOKBACK_DAYS`）。過去分をさかのぼって入れたいときはこの値を一時的に大きくします。

## テスト

```
node --test test/parser.test.js
```

メールの読み取りと振り分けのロジック（`Parser.js`）だけを対象にしています。Zaim への登録部分は実際のアカウントでの確認が必要です。
